# SAFE-ALERT-AI — PWA (Progressive Web App)

Ce dossier contient l'application web mobile (PWA).

## Fichiers

| Fichier | Description |
|---------|-------------|
| `index.html` | Interface mobile — appels API asynchrones |
| `sw.js` | Service Worker — mode hors-ligne |
| `manifest.json` | Manifest pour installation native |
| `logo.jpg` | Logo du projet |

## Installation

L'utilisateur peut installer l'application directement depuis le navigateur mobile (Chrome/Safari).

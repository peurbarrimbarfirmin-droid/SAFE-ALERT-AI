# SAFE-ALERT-AI — Notebooks d'analyse

## Pipeline d'analyse

| Notebook | Description |
|----------|-------------|
| `01_chargement_nettoyage.ipynb` | Chargement et nettoyage des données brutes |
| `02_analyse_exploratoire.ipynb` | Analyse exploratoire (EDA) |
| `03_tests_statistiques.ipynb` | Tests statistiques |
| `04_feature_engineering.ipynb` | Ingénierie des variables |
| `05_modelisation.ipynb` | Entraînement et évaluation des modèles |
| `06_interpretation.ipynb` | Interprétation SHAP et explicabilité |
| `07_analyse_residus.ipynb` | Analyse des résidus et validation |

## Utilisation

